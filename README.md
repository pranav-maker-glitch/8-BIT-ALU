
## 8-Bit Computer Architecture

### Block Diagram

![8-Bit Computer Block Diagram](Block%20diagram.jpeg)

### Description

The block diagram illustrates the data flow between
the main components of the computer architecture.

- **Bus:** Transfers data between components.
- **A-Register:** Stores the first operand for the ALU.
- **B-Register:** Stores the second operand for the ALU.
- **ALU:** Performs arithmetic and logical operations.
- **Clock:** Provides timing signals for sequential operations.
- **Bus Read and Write:** Controls data transfers
  between the bus and connected components.

### Working Principle

1. Data is transferred through the common bus.
2. The A-Register and B-Register store operands.
3. The ALU performs arithmetic and logic operations.
4. The result can be transferred back through the bus.
5. Clock pulses synchronize sequential operations.
